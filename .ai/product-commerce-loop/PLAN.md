# Product Commerce Loop Plan

## Loop

READ STATE -> DISCOVER -> IDENTIFY HIGHEST PRODUCT/COMMERCE GAP -> IMPLEMENT -> TEST -> VERIFY -> REVIEW -> COMMIT -> CONTINUE

## Phases

1. Mobile and product baseline.
2. Product add-ons, options, cart, and checkout.
3. Vendor storefronts and shareable commerce links.
4. Guest checkout.
5. Group ordering.
6. Feed restoration and commerce paths.
7. Multi-role customer mode.
8. Admin simplification for commerce support.
9. End-to-end quality assurance.
10. Performance and scale readiness.
11. Final integrated verification.

## Current Focus

Phase 1 discovery, then Phase 2 add-on/cart mobile correctness unless discovery identifies a higher product-commerce blocker.
