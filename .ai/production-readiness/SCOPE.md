# Scope

## In this first execution

- Preserve the dirty working tree.
- Establish branch/SHA and validation baseline.
- Discover the Next.js, API, authentication, database, infrastructure, PWA, test, asset, and deployment structure.
- Create all durable loop-memory documents.
- Produce initial route/asset inventories and prioritized tasks.
- Stop before remediation.

## Explicitly deferred

Application edits, schema changes, dependency upgrades, live-service tests, external messages, payments/refunds/transfers, branch creation, commits, push, preview deploy, native packaging, and production release.

## Safety classification

The repository handles identity, contact/location, order/chat, rider verification, financial, and privileged administrative data. Production data/credentials, legal bases, retention policy, KYC changes, wallet/custody design, destructive migration, evidence disclosure, and native background location require human review.
