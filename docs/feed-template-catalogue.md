# Feed template catalogue

Template version `2026-07-29.v1` is deterministic and does not depend on an
external language model.

Vendor examples:

- Welcome: `Now serving on LumeX Fud 🍽️` followed by a storefront action.
- New item: `Fresh on the menu at {vendor}: {item} for {price}.`
- Stock return: `{item} is available again at {vendor}.`
- Price drop: `{item} at {vendor} is now {current price}.`
- Popular: explicitly says the statement is based on verified paid/completed
  orders.
- Milestone: names only the exact completed-order threshold reached.

Official collection headings identify the area and current available option
count. Cheap-eats copy uses the configured maximum meal price only after
mandatory add-ons are included.

Templates must not use first-person vendor voice, unsupported ratings,
scarcity, demand, superlatives, or fake discount language. Emoji use is limited
to one relevant symbol in selected headings. Area text and direct action links
come from validated source records. A template change requires a new version so
provenance remains explainable.
